ゲーム内課金システム連携マニュアル (SDK Guide)

G-HUB公式：自作ゲームとリンクしてアイテム販売・チャプター解禁を行う方法

💡 面倒なライブラリ読み込みは一切不要！

G-HUBでプレイされるすべてのゲームには、自動的に window.GHUB オブジェクトが注入されます。
ゲーム内の任意の場所（ボタンクリック時など）から直接呼び出すだけで課金画面が開きます。

1️⃣ アイテム課金・購入リクエスト (requestPayment & purchaseDirect) 
// 💎 1. 通常の確認HUD付き課金（アイテム詳細をHUD表示してユーザーが確認）
const result = await window.GHUB.requestPayment({
  itemId: 'potion_heal_max',       // 一意のアイテムID (必須)
  itemName: 'エリクサー (HP全回復)', // 商品名 (必須)
  price: 50,                       // 価格（G-coin） (必須)
  consumable: true,                // true = 消耗品(何度でも) / false = 買い切り
  description: '全滅寸前でもHPとMPを完全回復する伝説の霊薬'
});

// ⚡ 2. 【シームレス課金】ポップアップを開かずゲーム画面から直接即時購入！
// ゲーム内ショップやバトル中のワンクリック購入に最適
const quickResult = await window.GHUB.requestPayment({
  itemId: 'instant_potion',
  itemName: '即時回復ポーション',
  price: 20,
  consumable: true,
  seamless: true // 👈 seamless: true でポップアップを完全スキップ！
});
// または短縮記法:
// const quickResult = await window.GHUB.purchaseDirect({ itemId: 'instant_potion', price: 20 });

if (result.success) {
  console.log('購入成功！', result.transactionId);
  player.hp = player.maxHp; // ゲーム内でアイテムを付与！
} else {
  console.log('購入キャンセルまたはコイン不足:', result.reason);
}
2️⃣ 買い切りアイテムの所有確認 (hasPurchased) 
// 🗝️ ゲーム起動時などに、プレイヤーが追加シナリオを購入済みか確認
const isChapter2Unlocked = await window.GHUB.hasPurchased('chapter_2_key');

if (isChapter2Unlocked) {
  // すでに購入済みならステージ選択画面をアンロック！
  enableChapter2();
}
3️⃣ 所持コイン数・投げ銭の呼び出し 
// 🪙 プレイヤーの現在のG-coin所持数を調べる
const coins = await window.GHUB.getUserCoins();

// 🎁 クリア画面等で作者への応援投げ銭を促す
const tipRes = await window.GHUB.sendTip(50); // 50G投げ銭

🌐 Unity WebGL, Godot, Phaser, 各種ゲームエンジン対応

Web標準の window.parent.postMessage を使用して通信するため、どのゲームエンジンからでも簡単に課金連携が可能です。

📡 1. 親ウィンドウへ課金リクエストを送信
// 親ウィンドウ(G-HUB)へ課金リクエストを送る
window.parent.postMessage({
  type: 'GHUB_REQUEST_PAYMENT',
  requestId: 'order_' + Date.now(),
  itemId: 'sword_excalibur',
  itemName: '聖剣エクスカリバー',
  price: 100,
  consumable: false, // 買い切り
  description: '攻撃力が+100される最強の武器'
}, '*');
📥 2. 決済結果をリスナーで受信
// 親ウィンドウからの返信を受け取る
window.addEventListener('message', function(e) {
  if (!e.data) return;
  
  if (e.data.type === 'GHUB_PAYMENT_SUCCESS') {
    // 決済完了！アイテムを反映
    console.log('課金成功:', e.data.itemId, e.data.transactionId);
    unlockItem(e.data.itemId);
  } else if (e.data.type === 'GHUB_PAYMENT_CANCELLED') {
    // ユーザーがキャンセルまたはコイン不足
    console.log('課金キャンセル:', e.data.reason);
  }
});

📋 コピペするだけで動くショップ画面サンプル

HTML5 Canvas ゲームや自作Webゲームにそのまま貼り付けて利用できるショップUIのサンプルコードです。 

<!-- ショップUIのボタン -->
<div style="background:#222; padding:15px; border-radius:10px; color:#fff;">
  <h3>🏪 ゲーム内ショップ</h3>
  <p>プレイヤーHP: <span id="hp-disp">10</span></p>
  <p>裏ステージ: <span id="stage-status">🔒 ロック中</span></p>

  <!-- 消耗品: ポーション購入 -->
  <button id="btn-buy-potion" style="background:#10b981; color:#fff; padding:8px 16px; border:none; border-radius:6px; cursor:pointer;">
    🧪 HP全快ポーション (30 G)
  </button>

  <!-- 買い切り: 裏ステージ解放 -->
  <button id="btn-buy-stage" style="background:#6366f1; color:#fff; padding:8px 16px; border:none; border-radius:6px; cursor:pointer;">
    🗝️ 裏ステージ解放 (100 G)
  </button>
</div>

<script>
  let playerHp = 10;

  // ゲーム起動時に裏ステージを購入済みか復元チェック
  window.addEventListener('load', async () => {
    if (window.GHUB) {
      const hasStage = await window.GHUB.hasPurchased('secret_stage_unlock');
      if (hasStage) {
        document.getElementById('stage-status').innerText = '✨ 解放済み！';
        document.getElementById('btn-buy-stage').style.display = 'none';
      }
    }
  });

  // ポーション購入ボタン
  document.getElementById('btn-buy-potion').onclick = async () => {
    if (!window.GHUB) return alert('G-HUB環境外です');
    
    const res = await window.GHUB.requestPayment({
      itemId: 'potion_heal',
      itemName: '全快ポーション',
      price: 30,
      consumable: true,
      description: 'HPが最大値(100)まで一気に回復します'
    });

    if (res.success) {
      playerHp = 100;
      document.getElementById('hp-disp').innerText = playerHp;
      alert('🎉 ポーションを購入しました！HP全回復！');
    }
  };

  // 裏ステージ解放ボタン
  document.getElementById('btn-buy-stage').onclick = async () => {
    if (!window.GHUB) return alert('G-HUB環境外です');

    const res = await window.GHUB.requestPayment({
      itemId: 'secret_stage_unlock',
      itemName: '裏ステージ 解放パス',
      price: 100,
      consumable: false, // 買い切り
      description: '高難度ボスが登場するエクストラステージが永久に遊べます'
    });

    if (res.success) {
      document.getElementById('stage-status').innerText = '✨ 解放済み！';
      document.getElementById('btn-buy-stage').style.display = 'none';
      alert('🎉 裏ステージがアンロックされました！');
    }
  };
</script>

🧪 今すぐこの画面で決済の流れをテストできます

ボタンをクリックすると、本番と同じ課金モーダルが起動し、購入からゲーム側への結果通知までの流れをリアルタイムに確認できます。
